# 方法学说明

对应脚本 `scripts/01`–`06`；本文只写口径与理由，逐步运行命令见 [REPRODUCE.md](REPRODUCE.md)，
数值见 [RESULTS.md](RESULTS.md)。

## 1. 数据来源与合规

MIMIC-IV（BIDMC，2008–2019 / v2.2 后续版本），经 PhysioNet 认证后获取，
存于本地 PostgreSQL，schema 为 `mimiciv_hosp` / `mimiciv_icu` / `mimiciv_derived` / `mimiciv_note`。
**本仓库不含任何患者级数据**，代码通过 SQL 在本地重建队列。使用源数据须独立取得
PhysioNet 认证并遵守 Data Use Agreement；引用格式见 [CITATION.cff](../CITATION.cff)。

## 2. ARDS 判定：柏林定义的生理学操作化

阳性须同时满足，且取**动脉血气**（`specimen LIKE 'ART%'`）：

- `PaO₂ / FiO₂ ≤ 300 mmHg`
- 同期 `PEEP ≥ 5 cmH₂O`
- 正在接受有创 / 无创机械通气

影像学"双肺渗出"要件在结构化数据中无法可靠判定，**未强制**。这是全文最重要的口径局限：
会高估发病率（心源性肺水肿、肺不张等被计入）。2024 全球新定义（HFNC ≥ 30 L/min、
S/F ≤ 315）未在 MIMIC-IV 侧启用，仅在本项目配套的院内专病库中做双轨判定。

## 3. 为什么 v1 标签不能用：循环论证

`01_extract_ards.py` 的 v1 标签是"ICU 住院期间任一次达标"，得到 17,664 例 /
11,555 事件（65.4%）。但实测 ARDS 起病时间中位 **5.2 h**，**84.6% 在入 ICU 24 h 内已达标**。

因此 v1 实质是"入院时是否已患 ARDS"。若用首日（0–24 h）特征去预测它：
**结局由 P/F 定义，而 P/F 同时是特征来源**，属同一生理窗口的 incorporation bias /
tautology。任何在此标签上报告的高 AUROC 都不构成"早期预测"。审稿中这是致命问题，
故 `02_define_label.py` 全面重建标签。

## 4. v2 主口径：前瞻式偶发 ARDS（incident ARDS）

| 要素 | 定义 |
|---|---|
| 人群 | 成人（≥18 岁）、**首次** ICU 住院、首 24 h 内机械通气、无慢性肺病 |
| 索引时点 t0 | ICU 入科 + 24 h |
| 基线窗 | [入科, 入科+24 h]，窗内**不得**出现任何一次达标 |
| 标签可判定 | 基线窗内至少 1 条动脉血气 |
| 结局窗 | (t0, t0+48 h]，即入科 24–72 h 内首次达标 → `y_ards72h` |
| 特征窗 | 首 24 h，**严格早于 t0** |
| 敏感性标签 | `y_ards48h`（视野 24 h）、`y_ards7d`（视野 144 h） |

管线队列 3,723 例 / 527 事件（14.2%）。

### 歧义层与主分析收紧

305 例基线 `P/F ≤ 300` 但**无 PEEP 记录**：既不能判 ARDS，也不能判 ARDS-free。
该层 48 h 发病率 27.9%（其中 `P/F ≤ 200` 者达 36%），若一律记为阴性即标签污染。
故主分析要求 **`min_pf_base > 300`**，歧义层仅用于敏感性分析。

**主分析队列：3,418 例 / 442 事件（12.9%）**。

## 5. 特征与泄漏控制

- 所有基线特征取自 `[入科, t0)`，时间列（如 `t_end`、`first_vent_start`）通过 dtype 白名单剔除。
- `04_multimodal_features.py` 构造四层：**呼吸力学**（平台压、驱动压、Vt/PBW、顺应性）、
  **气体交换**（PaCO₂、A-a 梯度、血气乳酸）、**循环灌注**（血管活性药、去甲当量、尿量、RRT）、
  **感染炎症**（`susp_infection_24h`、抗生素、纤维蛋白原、CK、乳酸）。
- `susp_infection`（全住院最大值）含未来信息，已剔除，只保留 `susp_infection_24h`。
- 可得性先实测后使用：`mimiciv_note.radiology` 为空表、hs-CRP 覆盖率 0%、
  铁蛋白 3.1%、D-二聚体 0.7% → 本研究"多模态"严格限于**结构化多模态**，不含影像与组学。

## 6. 模型与评估（03）

划分：分层随机 70/30，`SEED = 42`；测试集 n = 1,026 / 133 事件。

| 臂 | 定义 |
|---|---|
| M1 | 8 个床旁可得变量的简约 logistic 回归 |
| M2 | 全变量 L2 logistic 回归（缺失指示 + 中位数填补 + 标准化） |
| M3 | HistGradientBoosting |
| 参照 | SOFA 单变量、基线 P/F 单变量 |

评估：DeLong 95%CI、bootstrap AUROC、AUPRC、Brier、**校准斜率**、Hosmer–Lemeshow、
决策曲线（DCA）、置换重要性。

> **校准斜率必须用 logistic 回归拟合 `logit(p) → y`，不能用 OLS。**
> 本项目实测真值 1.0 时 OLS 给 0.095，系统性低估近 10 倍。历史脚本中
> `03` / `05` 用 `C=1e6` 的强正则 LR、`06` 用 `penalty=None`，
> 差异不影响各自表格，但新分析请统一用 [`scripts/stats_core.py`](../scripts/stats_core.py)。

## 7. 增量价值（05）

同一 train/test 划分下逐层加入 S0 BASE → S1 +RESP → S2 +GAS → S3 +CIRC → S4 +INF，
用**配对 bootstrap（2000 次）**检验 ΔAUROC，避免把两次独立抽样之差当作增量。
另设 16 变量的 MM-parsimonious 简约模型评估床旁可用性。

## 8. 动态 landmark 预测（06）

- landmark **24 / 48 / 72 h**，固定预测视野 **24 h**。
- 风险集：L 时点仍在 ICU、且 L 前未发病；L 前发病 / 已离科者剔除。
- 删失：主分析要求完整 24 h 观察（L+24 前离科或死亡者剔除）；
  敏感性 A 将删失记为阴性，敏感性 B 把视野改为 48 h。
- 轨迹摘要：累计 mean / min / max、近 12 h 末次值、近 24 h OLS 斜率。
- **主分析用预设简约集**：`CORE_STATIC` 23 + `CORE_TRAJ` 24 = 47 变量。
  157 / 239 个特征配 322 个事件必然噪声主导，那样"静态 vs 动态"的比较没有信息量。
- 正则强度由训练集内层 CV（负对数损失）选定，不手工设 C。
- 配对 ΔAUROC 用**按阳/阴性分层**的 bootstrap，保证每次重抽样事件数恒定。

## 9. 可复现约定

- 编号脚本 `NN_*.py` 严格按序执行，每一步都把中间产物落盘，便于定位分歧。
- 所有随机过程统一 `SEED = 42`；`results/*_meta.json` 记录运行时参数。
- 数据库连接参数集中在 `scripts/ards_config.py`，密码只从 `PGPASSWORD` / 本地 `.env` 读取。
- 历史脚本保留内联统计实现以**逐位复现**已发表表格；`stats_core.py` 是新增分析的规范实现，
  两者差异见该文件顶部说明与 `tests/test_stats_core.py`。

## 10. 已知局限

1. 影像学要件缺失 → 生理学口径高估 ARDS 发病率。
2. 无外部验证：eICU 受地区政策限制不可下载；院内队列尚在录入。
3. 后段 landmark 功效不足：48 h / 72 h 测试集事件仅 36 / 26 例，CI 极宽，
   "无显著差异"不能等同于"无差异"。
4. 入选偏倚：要求存活至 24 h 且基线无 ARDS，早期恶化者被排除。
5. `bg.fio2` 缺失约 25%；用呼吸机 FiO₂ 补算仅多恢复 2.8% 例数，故未回改 01，
   但会造成少量标签误分类。
6. 主队列已剔除 `P/F ≤ 300` 者 → **range restriction**，基线 P/F 单变量 AUROC 仅 0.581，
   不可误读为"氧合不重要"。
